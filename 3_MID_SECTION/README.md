# MAUS gondola/pod MID section

## Overview
The central section of the Maus gondola is the part where the servos are mounted and to which the suspension bracket for the paraglider wing is to be attached later.
The Maus RC paramotor gondola supports mini (35.5x15) and standard (40x20) servos.<br/>

## Guide
### step 1 
If you used standard sizes in the previous steps, you can download the Midsection_yyxzz.stl file. Choose the file that matches your servo size. When 3D printing, you can experiment with the infill percentage and wall thickness. My POD was printed with 33% infill and a wall thickness of 3 lines.<br /><br/>
If you used different servo dimensions in previous steps, download the "maus_midsection.FCStd" file and open it in FreeCAD. Just like in the previous steps, you can adjust the dimensions using the selection boxes; no 3D design knowledge is required. After adjusting the dimensions, you may need to click the refresh button. Then, export the file to STL and 3D print it.<br />

### step 2 
Once this part has been printed, it is a good time to test-fit the servos.<br/>
Position the servos with their brackets and screw them in place temporarily. Check that everything fits and aligns properly.<br/>
If this is not the case, you may need to adjust the dimensions and reprint the part.<br/>
If everything is correct, remove the servos.<br/>
