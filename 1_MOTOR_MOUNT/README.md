# Motor mount backplate

## Overview
The motor needs to be mounted on a flat plate at the back of the Maus gondola. This plate must be made of a strong material, such as metal, carbon fiber, or fiberglass, and be 1.5 to 2 mm thick. A plastic plate would wear out, break, or warp too quickly.

The 3D design/print in this repository is a template you can use to create a backplate from a strong material using simple tools like a handsaw and a drill; no CNC is required.

The STL files in this repository contain the 3D design that you can use directly in your 3D printer slicer software to print the template. There is one STL file for motors with a 16x19 mounting hole pattern (common for 28xx size brushless motors) and another for motors with a 25x25 pattern (common for 35xx size brushless motors)

If your motor has a different layout, or if you wish to adjust the template's dimensions (such as thickness or height), you can do so by opening the FCStd file in FreeCAD. You do not need any 3D design experience; these adjustments can be made simply by using a convenient selection box. Once you have made the changes, click "Export" and select STL (or another format compatible with your 3D printer slicer software).
