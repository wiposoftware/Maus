# MAUS gondola/pod Front section

## Overview
The front of the MAUS gondola consists of three parts:
  - the cockpit
  - the nose cone
  - the canopy
Currently, only an STL file is available for each component.

## Guide
### step 1 
Download the "backsection.stl" file and use it in your 3D slicer program to print this part on a 3D printer.
I used 3 lines for wall thickness and 33% infill.<br />
