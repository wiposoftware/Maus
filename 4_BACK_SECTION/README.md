# MAUS gondola/pod BACK section

## Overview
There is little to say about the back section. This is the section where the ESC and motor are mounted.
Currently, only the .stp file is available (no FreeCAD file).

## Guide
### step 1 
Download the "backsection.stl" file and use it in your 3D slicer program to print this part on a 3D printer.
I used 3 lines for wall thickness and 33% infill.<br />
<img width="320" alt="backsection" src="https://github.com/user-attachments/assets/e2bf61e5-4b46-4414-8c50-654d221f4f84" /><br /><br />

### step 2 
When this part is printed you have to insert 6 x M3 inserts. These inserts need to be pushed from the inside. 
Using M3 inserts is not mandatory. You can also mount the motor backplate using a screw and nut, but given the limited space, that is not exactly easy.<br />
<img width="320" alt="backsection1" src="https://github.com/user-attachments/assets/a0378cbc-83ba-4b67-b728-8c8900e74772" /><br /><br />

### step 3
Once the M3 inserts are installed, you can check whether the motor backplate and the motor fit into this part. If everything fits correctly, set the motor and backplate aside.<br />
<img height="320" alt="backsection2" src="https://github.com/user-attachments/assets/df8b91d9-ce89-485b-91e0-e7c83ec23404" /><br /><br />

### step 4
Now use a good Epoxy glue to glue this back section part to the mid section part. The 7 mm wide joint, in combination with epoxy, can support sufficient weight/load.
DO NOT use CA glue! CA is not strong enough and your gondala will break. <br />
